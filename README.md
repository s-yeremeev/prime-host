## Що покрито

- `tests/contacts.spec.ts` — сторінка `/contacts`: створення, редагування (включно зі
  збереженням стану чекбоксів) та видалення контакту.
- `tests/register-domain-single.spec.ts` — пошук одного домену з зазначеною доменною
  зоною (`.com`, `.net`, `.org`), додавання до кошика, перевірка що TOTAL у кошику
  збігається з ціною на сторінці пошуку.
- `tests/register-domain-multiple.spec.ts` — пошук домену без доменної зони, додавання
  3 вільних варіантів до кошика, перевірка що TOTAL збігається із сумою цін.

## Встановлення та запуск

### 1. Встановити залежності

```bash
npm install
```

### 2. Встановити браузер для Playwright

```bash
npx playwright install chromium
```

### 3. Налаштувати env

```bash
cp .env.example .env
```

Заповнити `BASE_URL`, `USER`, `PASSWORD` значеннями тестового акаунта.

### 4. Запустити тести

```bash
npx playwright test
```

Перший запуск виконує проєкт `setup` (логін через UI, збереження сесії у
`playwright/.auth/user.json`), решта тестів використовує цю збережену сесію.
