## Встановлення та запуск

### 1. Встановити залежності

```bash
npm install
```

### 2. Встановити браузер для Playwright

```bash
npx playwright install chromium
```

### 3. Налаштувати env

```bash
cp .env.example .env
```

Значення за замовчуванням підходять для запуску без змін. Що можна змінити — розділ
["Змінні середовища"](#змінні-середовища) нижче.

### 4. Запустити тест (безпечний режим — за замовчуванням)

```bash
npx playwright test
```
